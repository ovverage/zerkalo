# Демонстрация · PEEP · 60–90 секунд

**Статус: сценарий готов, запись с живой камерой ещё не предоставлена.** Записывает владелец или участник с согласия. Не заменять человека симуляцией без заметной подписи.

## Ролик на 85 секунд

Сначала снять реальный проход целиком (несколько минут), затем смонтировать фрагменты. Подписывать сокращение ожидания/переходов; не ускорять показ ошибки и зачёт следующего повтора. 75 секунд активного режима не помещаются вместе с полным запуском и тремя движениями в 90 секунд — здесь честно используются фрагменты длинной записи.

| Время ролика | Кадр / действие | Что видно и что сказать |
| --- | --- | --- |
| 0–8 с | Публичный HTTPS-сайт, «Включить камеру», разрешение. При долгой загрузке — подписанное сокращение. | «PEEP. Зеркало: тренировка и управление телом, без контроллера». |
| 8–18 с | Урок, одна рука в сторону выбирает пункт, крест подтверждает. | «Левая — назад по пунктам, правая — вперёд, крест — подтвердить. Между командами опускаем руки». |
| 18–36 с | Фрагменты программы MOTION: полный присед, синхронный jumping jack, жим согнутыми локтями с возвратом. | Видны три разных движения и три соответствующих счётчика. Не показывать только руки или один итоговый кадр. |
| 36–46 с | Крест → пауза; правая рука → «Как выполнять»; крест → помощь; возврат → продолжение. | Камера со стороны подтверждает отсутствие касаний после разрешения. |
| 46–67 с | «Исправь движение»: естественно короткий цикл, конкретная подсказка, подсвеченные суставы, следующий комфортный полный цикл. | Крупно показать причину отказа, затем «Теперь достаточно глубоко — повтор засчитан». **Не просить сделать опасную ошибку.** Если отклонений не возникло, показать честный успешный подход и подписанный синтетический пример отдельно, не выдавая его за живую проверку. |
| 67–79 с | Фрагмент итогов 75 секунд: зачтённые/все попытки, названные исправления; при наличии второй сопоставимой попытки — сравнение. | «Подтверждаем измерением следующего повтора. Без ошибок — хороший результат». Монтаж таймера обозначить. |
| 79–85 с | Выбор «К тренировкам» или «Ещё раз» жестом, ссылка на сайт и репозиторий. | «Кадры обрабатываются на устройстве. Код, проверки и ограничения открыты в README». |

## Что сохранить вместе с видео

- Версия приложения, устройство, браузер/WebView и модель.
- Полная исходная запись прохода (по согласованию с участником) для проверки монтажа.
- Заполненный [протокол живой проверки](live-check.md).
- Реальные числа счётчика и подсказки; не перерисовывать их поверх записи.

## Короткая очная проверка жюри

Начать с выделенной карточки «Зеркало: исправь движение», посмотреть видеопоказ, выполнить 75 секунд в обычном темпе. Поставить паузу крестом, открыть и закрыть помощь без касания, затем продолжить. Посмотреть итог и выбрать меню. Отдельно пройти «Три движения · MOTION» (3 + 3 + 3), чтобы проверить присед, джамп и жим одной фронтальной камерой. Если камеры нет — открыть явно подписанную симуляцию; она демонстрирует логику, но не точность распознавания.
