# Зеркало для Android · 1.3.0

Android 7.0+ (API 24), актуальный Android System WebView, камера. Приложение работает локально: модели, runtime, шрифты и 11 видеопоказов включены в APK. Регистрация и сервер не нужны.

## Что изменилось

- Четыре нижние вкладки: «Тренировки», «Упражнения», «Прогресс», «Настройки».
- Отдельная прокрутка содержимого. Навигация и кнопки тренировки занимают собственное место, а не перекрывают экран. На небольшом экране доступны все упражнения и настройки.
- Непрозрачный фон меню и видеотеки: текст читается при светлом изображении камеры.
- Крупные кнопки помощи, паузы и завершения во время тренировки; закреплённый старт на экране видеопоказа. В горизонтальном положении кнопки тренировки переходят вправо.
- Полный основной маршрут доступен жестами: левая рука в сторону — предыдущий пункт, правая — следующий, крест — подтвердить. Во время упражнения работает только крест для паузы; по умолчанию на паузе он продолжает. Навигация также доступна в помощи и результатах. Удержание, отпускание, выделение и чтение длинных разделов. Две руки вверх не вызывают команд; курсора и кругов нет.
- Первой показана программа «Исправь движение» на 75 секунд. Результат содержит долю зачёта и названия исправлений; сравнение — только для двух полных сопоставимых попыток.
- Подготовка занимает одну короткую полосу: показывается только главная причина, например «Встань в кадр». Полная инструкция открывается по «?» или «Как выполнять».
- Убраны статус «Камера подключена» в меню и повторяющиеся пояснения поверх камеры.
- Системный «Назад» закрывает видеопомощь или ставит тренировку на паузу. Завершение требует повторного нажатия. После сворачивания тренировка остаётся на паузе.
- Голос, звуки, отражение камеры и три модели вынесены в настройки. Сохранено ограничение речи: общая пауза от 10 секунд, повтор одной ошибки — от 30 секунд.

## Установка и обновление

Скачайте [APK 1.3.0](https://github.com/ovverage/zerkalo/releases/download/v1.3.0/zerkalo-1.3.0.apk), откройте его на телефоне и подтвердите установку. Если Android запрашивает разрешение на установку из этого источника, разрешите его для приложения, которым открываете APK. Затем запустите «Зеркало» и разрешите камеру при старте.

Это подписанная **debug-сборка для прямой установки и проверки**, не публикация в Google Play. Package ID — `kz.admithackathon.zerkalo`, версия — `1.3.0`, versionCode — `4`. Подпись совпадает с APK 1.2.0, поэтому его можно обновить без удаления приложения. Сборка, подписанная другим ключом, потребует другой процедуры установки; удаление приложения стирает локальную историю.

SHA-256 публичного сертификата подписи:

```text
2df8c02595a10daaa7bdc0e2cfb68f44adcc38cade7497c3d13b3fbb0f77e87c
```

Рядом с APK в релизе публикуется файл `.sha256` для проверки целостности загрузки. Ключ подписи в репозиторий не входит.

## Сборка

Нужны Node.js 22+, JDK 21, Android SDK API 36 и Build Tools 36.0.0. Установите SDK и примите его лицензии через Android Studio или штатные инструменты Android.

```bash
npm ci
npm run typecheck
npm test
npm run android:apk
```

Результат — `dist/zerkalo.apk`. Скрипт ищет JDK и SDK в стандартных каталогах; можно задать `JAVA_HOME` и `ANDROID_HOME`. Команда пересобирает веб-приложение и синхронизирует его с Android перед Gradle. Обычная сборка сайта очищает `dist/`, поэтому готовый APK следует сохранить отдельно перед ней. На другой машине debug-ключ обычно отличается.

Для проверки Android-проекта:

```bash
cd android
./gradlew :app:lintDebug
```

## Устройство интерфейса

Capacitor 8 `SystemBars` передаёт системные отступы в CSS. Оболочка `.ui` применяет их один раз через `--app-safe-*`; предусмотрен fallback на `env(safe-area-inset-*)`. Нижнее меню находится вне прокручиваемого `.screenhost`. В старых WebView встроенный механизм Capacitor также учитывает системные панели. Конфигурация находится в `capacitor.config.ts`, общая геометрия — в `src/styles/shell.css`, оформление APK — в `src/styles/android.css`. В браузере используются верхнее меню и `web.css`; Android-слой включается только внутри Capacitor.

## Проверка 30 сентября 2026

- TypeScript: без ошибок; 97 автоматических тестов прошли, включая игнорирование поднятых рук и защиту от повторного срабатывания удержанного креста.
- Браузерный сценарий реальных экранов с синтетической позой: 320×568, 360×740 и 740×360, системные отступы 24 px сверху и снизу. Проверены три урока и полный маршрут без касаний: выбор программы, видео, старт, пауза, помощь, чтение длинных разделов, продолжение, две попытки и сравнение, три движения до результата, повтор и возврат. Проверены возврат из видеопоказа, запуск и переключение паузы крестом, отсутствие команд при поднятых руках и высота подсказки подготовки.
- Высота подготовки проверена: не больше 128 px и четверти экрана. На 360×740 визуально проверены помощь и сравнение; тёмный фон сохраняет контраст текста.
- `assembleDebug` и `lintDebug`: успешно; lint — 0 ошибок, 18 предупреждений о ресурсах и настройках Android-шаблона/доступных версиях зависимостей.
- Проверены подпись, versionCode, package ID, разрешения, совпадение файлов внутри APK с текущей веб-сборкой; 3 модели, 6 файлов runtime и 11 MP4 включены. Исходники, тесты, карты исходников и ключи подписи в веб-ресурсы APK не попали.

**На физическом Android и в эмуляторе эта версия не запускалась:** подключённого устройства и установленного эмулятора не было. Проверки браузерной геометрии не заменяют проверку WebView, системной кнопки «Назад», разрешения камеры и реального распознавания на телефоне.
