# Баннер

- `banner.png` — готовый баннер для README, 1600 × 640.
- `banner.svg` — редактируемый векторный исходник с текстом и схемой позы.

Палитра повторяет интерфейс: тёмный синий фон, светлый текст, бирюзовые акценты. Схема справа — иллюстрация принципа работы, не скриншот измерения конкретного человека.

Чтобы пересоздать PNG после изменения SVG, установите `rsvg-convert` и выполните из корня проекта:

```bash
rsvg-convert docs/assets/banner.svg -o docs/assets/banner.png
```

SVG использует Inter с запасным DejaVu Sans; при необходимости установите Inter для совпадения шрифта при экспорте. Обычная сборка приложения не требует пересоздания баннера.
