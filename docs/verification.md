В последнем запуске стенда Heavy первый результат изображения получен за 844 мс; после смещения/поворота — примерно за 141–142 мс. Занятость UI при вызове фонового распознавателя — 0–1 мс. Это разовая проверка на данной машине, **не** измерение постоянного FPS камеры. Рабочая панель приложения считает новые ответы отдельно от перерисовок; низкая частота предлагает Lite.

## Автоматические регрессии

- Удержание жеста не создаёт цепочку команд после перехода экрана и потери позы; опускание рук снова разрешает ввод.
- Курсор даёт одинаковую точку после переноса/масштабирования человека и достигает нижних элементов мобильного экрана.
- Пауза и длинная потеря суставов обрывают незавершённый повтор. Старый ответ модели не увеличивает время удержания.
- Ложные движения: присед лёжа, руки без ног в jumping jack, подъём прямых рук вместо жима; раздельное достижение максимумов рук и ног.
- Исправление признаётся только после зачтённого повтора; без предыдущего нарушения исправление не выдумывается.
- Таймер завершается через 75 секунд даже при одном обновлении в секунду. Пауза между кадрами учитывается точно; минута без кадров на паузе исключена. Без завершённых движений нет положительной оценки техники.
- Сценарий симуляции проходит все три настоящих анализатора до девяти зачтённых повторов и исправлений.
- Частота модели не растёт от чтения/отрисовки старого результата, падает при остановке ответов.
- Отказ камеры, отсутствие устройства и занятость дают разные сообщения; зависшая загрузка Worker завершается ошибкой.
- Общая пауза речи 10 секунд, повтор правила 30 секунд, предупреждения молчат, очереди нет.

Команды: `npm run typecheck`, `npm test`, `npm run build`, `npm run verify:release`. Браузерные стенды запускаются отдельно через `npm run dev`; CI без браузера не заменяет эти проверки.

## Протокол владельца: живая камера (обязательный незавершённый пункт)

Проверять на том устройстве и браузере, которые будут на защите. Нужны участник, камера и наблюдатель со счётчиком. Не выполнять через боль; выбирать удобный темп и амплитуду. Ошибки суставов намеренно не провоцировать.

1. **Запуск.** Сбросить только обучение через кнопку «Жесты» либо использовать отдельный профиль браузера. Разрешить камеру. После этого до результата не касаться мыши/клавиатуры. Записать браузер, размер кадра, модель, освещение и измеренные результаты/с.
2. **Управление.** Пройти три урока. Проверить меню и «Выше / Ниже», старт, паузу, помощь и возврат. Удержать один жест 5 секунд: должна сработать одна команда. Опустить руки и повторить: должна сработать новая.
3. **MOTION.** По 3–5 обычных повторов каждого движения. Встать сначала по центру, затем левее/правее, оставаясь целиком в кадре. Не менять высоту камеры между тремя упражнениями. Наблюдатель отмечает фактические движения и счёт приложения.
4. **Неполная амплитуда.** Если естественно получился короткий повтор, проверить конкретность подсказки и следующий комфортный полный повтор. Не преодолевать ограничения ради порога. Зафиксировать ложные отказы и лишние зачёты; не заменять это вымышленной статистикой.
5. **Прерывания.** Прикрыть рабочую кисть / выйти из кадра на секунду, затем вернуться. Счёт приостановлен, видна причина; пропажа не является «исправлением». Поставить паузу посреди движения: остаток не должен дать повтор.
6. **Боковой ракурс.** Отжимания/планка с камерой невысоко сбоку; целая видимая сторона. Для управления безопасно встать лицом к камере, поставить паузу, открыть и закрыть помощь.
7. **75 секунд.** Пройти две попытки «Исправь движение». Свернуть вкладку: должна включиться пауза, после возврата требуется команда продолжения. Убедиться, что реальные результаты сохраняются и сравниваются; без нарушения нет выдуманного исправления.
8. **Телефон и свет.** Повторить короткий маршрут в вертикальном браузере; проверить белый/яркий и тёмный фон, читаемость с расстояния 2–3 м, отсутствие перекрытия кнопок.
9. **Доступ.** На будущей публичной HTTPS-ссылке открыть инкогнито без входа в GitHub. Проверить камеру, модели, видео и итог. В другой сессии отказать камере и проверить возможность повторного запуска/симуляции.
