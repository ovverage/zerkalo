## Что изменилось и почему это проверено

- **Три разных команды.** Крест подтверждает, левая рука выбирает предыдущий пункт, правая — следующий. Поднятые обе руки не команда. Для руки в сторону нужны видимые опорные суставы, прямой локоть, горизонтальная вытянутая рука и опущенная другая рука. Во время упражнения выбор выключен. Один удержанный жест не проходит цепочку экранов, повторный результат модели не подтверждает отпускание.
- **Одна подсказка — соответствующая подсветка.** После короткого повтора сохраняются причина отказа и подсветка нужной части тела. `CorrectionTracker` дополнительно проверяет конечные числовые измерения и правило того же упражнения. Потеря тела не подтверждает исправление. В итогах названия подтверждённых правил сохраняются отдельно от замечаний.
- **Сравнение без выдуманных улучшений.** Две полные 75-секундные попытки, минимум по три завершённых цикла, те же план/модель/версия правил. Смена модели внутри попытки, старые записи, ранний выход и симуляция не допускаются. Свежая запись исключается по ID. Доля зачёта имеет явный знаменатель. Отсутствие ошибок — успешный результат, а не повод просить ошибаться.

## Не выполнено — блокеры уверенной оценки 95/100

1. Живая камера на 2–3 людях, включая Android: точность счёта, жесты с расстояния, освещение, смещение, перекрытия, ложные отказы и лишние зачёты **не измерены**. Владелец получил [короткий протокол с таблицей](live-check.md); заполненных результатов пока нет.
2. Установка APK на физический телефон, его разрешение камеры, WebView, системный «Назад» и сворачивание не проверены на устройстве. Браузерный стенд проверяет только код маршрута, имитацию lifecycle и геометрию.
3. Реальное демонстрационное видео ещё не записано. Подготовлен [сценарий на 85 секунд](demo-script.md), включая честно обозначенный монтаж 75-секундной попытки.
4. Порогам нужны реальные данные на разных людях; нет клинической валидации и гарантии универсального распознавания. Видеозапись движений через модель также не проверялась. Нет Service Worker, облачной истории и гарантированного offline-режима сайта.

## Как повторить

```bash
npm ci
npm run typecheck
npm test
npm run build
npm run verify:release
npm run preview -- --host 127.0.0.1
```

Production: `http://127.0.0.1:4173/app/`. Для браузерных стендов отдельно `npm run dev -- --host 127.0.0.1`:

- `/test/handsfree.html` — самостоятельный маршрут, итог `PASS … NO TOUCH`; `?insets` имитирует отступы. `?insets&comparison` останавливается на сравнении, `?insets&help` — в помощи. Тренировки остаются в памяти стенда и не записываются в пользовательскую историю.
- `/test/browser.html` — кнопка запуска настоящей Heavy на указанной фотографии.
- `/test/guidance.html` — реальные инструкции поверх белого фона.

Стенды не включаются в опубликованные файлы. [Android-сборка и ограничения](android.md). Размер и SHA-256 опубликованного APK хранятся в `scripts/android-release.json`; бинарный файл — в GitHub Release, а не в истории исходников.
