# Демо без камеры

Встроенная демонстрация использует явно обозначенные **синтетические координаты** из `src/demo/`. Файл `demo.mp4` больше не требуется.

Симуляция показывает присед, jumping jacks и жим через обычный движок приложения: незачтённую попытку, подсказку, измеренное на синтетических данных исправление и итог. Она не запускает MediaPipe и не подтверждает точность на людях. Демонстрационные результаты не сохраняются в личную историю.

11 анимированных MP4 в `public/exercises/` — отдельные обучающие видеопоказы, а не реальные записи людей.

Для реальной валидации снимите обычные движения с согласия участника по `docs/verification.md`. Не просите намеренно выполнять опасные ошибки.
