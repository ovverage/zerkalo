# Демо-ролик

Сюда нужно положить файл `demo.mp4` — короткую запись (20–40 секунд), на которой
человек выполняет упражнения перед камерой.

Зачем: кнопка «Демо без камеры» на стартовом экране прогоняет через этот ролик
весь конвейер распознавания. Если у проверяющего нет камеры или он не может дать
к ней доступ, приложение всё равно можно пройти целиком.

Требования к записи:

- формат MP4 (H.264), чтобы игралось во всех браузерах;
- человек в полный рост, фронтально, на расстоянии 2–3 м;
- подойдут приседания или jumping jacks — они есть в программе «Быстрая разминка»;
- полезно снять и заведомо неправильные повторения: неглубокий присед,
  сведённые колени — тогда в демо видно работу режима «ошибка»;
- размер желательно до 10 МБ, иначе заметно вырастет вес репозитория.

Файла нет — приложение об этом честно скажет и предложит включить камеру.
Основной режим от демо-ролика не зависит.
